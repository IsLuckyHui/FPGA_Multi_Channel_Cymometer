# 基于 FPGA 的多通道等精度频率计（LCD 触摸显示版）

一个在 FPGA 上实现的 **18 通道等精度数字频率计**，通过 RGB LCD 实时显示各通道频率值，支持**触摸翻页**查看全部通道，并由 **PCF8563 实时时钟**在屏幕上显示日期与时间。

## 项目简介

- 采用**等精度测频法**（多周期同步测量），在 1.5s 实际闸门内同时对参考时钟与被测时钟计数，消除了普通直接测频法对低频信号测量误差大的问题，全频段测量精度只与参考时钟精度有关。
- 每个通道配备独立的频率计核心与**自研除法状态机**（`div_fsm`），不占用 FPGA 内部硬除法器资源。
- 频率测量结果经 **binary2bcd（移位加 3 算法）** 转换为 BCD 码后，以 "XXXXXXXXX Hz" 的格式渲染到 LCD 上。
- 屏幕右上角通过 I2C 读取 **PCF8563 RTC** 芯片，实时显示 `20YY-MM-DD` 与 `hh:mm:ss`。
- 支持**电阻/电容触摸屏**（FT 系列触摸芯片），点击屏幕右下角翻页区域即可在"通道一 ~ 通道九"与"通道十 ~ 通道十八"两页之间切换。
- 兼容多种 RGB LCD 屏（上电自动读取屏幕 ID 适配分辨率与像素时钟）：
  - 4.3 寸 480×272
  - 4.3 寸 800×480
  - 7 寸 800×480
  - 7 寸 1024×600
  - 10.1 寸 1280×800

## 等精度测频原理

```
频率计算公式：  Fx = (cnt_fx × Ffs) / cnt_fs

  cnt_fx ：实际闸门内被测时钟的计数个数
  cnt_fs ：实际闸门内 100MHz 参考时钟的计数个数
  Ffs    ：参考时钟频率 100MHz
```

软件闸门（1.5s）由系统时钟产生，再同步到被测时钟域，得到与被测信号**同步的实际闸门**，从而保证对 cnt_fx 的计数无 ±1 误差；闸门下降沿后在基准时钟域锁存两个计数值，送入除法器求得频率。一次完整测量周期为 1.6s。若 2s 内闸门未再拉高，则判定被测信号断开，显示清零。

## 工程结构

```
├── top_cymometer.v      顶层模块：例化 PLL、18 路频率计、LCD 显示、触摸、RTC
├── cymometer.v          等精度测频核心（单通道）：闸门产生、计数、除法控制
├── div_fsm.v            自研除法器状态机（移位减法除法，三段式状态机）
├── binary2bcd.v         二进制转 BCD（移位加 3 / Double-Dabble 算法）
├── clk_test.v           测试时钟产生模块（默认输出 5Hz，用于自校验）
├── lcd_rgb_char.v       LCD 显示顶层：LCD 驱动 + BCD 转换 + RTC 数据汇聚
├── lcd_display.v        LCD 画面渲染模块（★ 工程中实际使用的优化版）
├── lcd_display--.v      LCD 画面渲染模块（最初版本，仅用于对照学习）
├── lcd_driver.v         RGB LCD 时序驱动（行场同步、DE、像素坐标生成）
├── rd_id.v              上电读取 LCD 屏幕 ID（复用 RGB 总线）
├── clk_div.v            根据 LCD ID 分频产生对应像素时钟
├── pcf8563_ctrl.v       PCF8563 RTC 控制模块（初始化 + 循环读取时间）
├── i2c_dri_date.v       I2C 底层驱动（供 PCF8563 使用）
├── touch_top.v          触摸顶层：I2C 驱动 + 触摸控制
├── touch_dri.v          触摸芯片驱动（FT 系列）：坐标解析、翻页判断
└── i2c_dri_touch.v      I2C 底层驱动（支持连续读写多寄存器，供触摸使用）
```

## 关于两个 lcd_display 文件的重要说明

> **本文件夹中存在两个功能相同、写法不同的文件：`lcd_display.v` 与 `lcd_display--.v`。**
>
> - **`lcd_display.v`** —— 工程中**正式使用**的代码，是对最初版本进行优化后的改版：
>   - 用 `function`（`hanzi_bit` / `hanzi_bit_48`）统一封装字模点位提取；
>   - 用**比较器累加**代替除法求行列号，用**移位**代替乘法计算字模索引；
>   - 增加了 18 通道分页显示、RTC 日期时间、触摸坐标、翻页图标等显示区域；
>   - 大量区域判断复用同一套相对坐标计算逻辑，代码量大幅精简。
> - **`lcd_display--.v`** —— **最初版本**的项目代码。它把每一个显示字符区域的判断和字模取点都**逐段展开**写出来，没有做任何抽象，因此**更方便初学者理解"像素坐标 → 字模点位 → 颜色输出"这一赋值字模的完整逻辑**。
>
> ⚠️ 综合工程时**只需加入 `lcd_display.v`**（两文件模块名相同，同时加入会报重名冲突）。
> 保留 `lcd_display--.v` 仅用于阅读对照，建议先读它、再读优化版。

## 关键参数（top_cymometer.v）

| 参数 | 默认值 | 说明 |
|---|---|---|
| `CNT_GATE_MAX` | 75_000_000 | 闸门总周期 1.5s（50MHz 系统时钟） |
| `CNT_GATE_LOW` | 12_500_000 | 闸门低电平时间 0.25s |
| `CNT_TIME_MAX` | 80_000_000 | 一次测量总时长 1.6s，同时用于信号断线判据 |
| `CLK_FS_FREQ`  | 100_000_000 | 等精度参考时钟频率 |
| `DATAWIDTH`    | 57 | 除法器位宽（被除数 = cnt_fx × 100MHz 需 57bit） |
| `CH_NUM`       | 18 | 通道总数（LCD 每页显示 9 路） |
| `TIME_INIT`    | 48'h26_09_22_07_30_00 | RTC 上电初始时间（年月日时分秒） |

## 硬件资源

- FPGA 开发板（工程按 50MHz 系统时钟设计，正点原子达芬奇等开发板可直接适配）
- RGB LCD 屏（支持上文列出的 5 种分辨率，屏幕 ID 通过板上电阻自动识别）
- FT 系列电容触摸屏
- PCF8563 RTC 芯片（I2C 地址 7'b101_0001）
- PLL 时钟 IP：`clk_wiz_0`（输入 50MHz，输出 100MHz 与 133.33MHz）

## 使用方法

1. 在 Vivado 中新建工程，将上述 `.v` 文件加入工程（**不要同时加入 `lcd_display.v` 与 `lcd_display--.v`**）。
2. 添加 `clk_wiz_0` PLL IP：输入 50MHz，输出 `clk_out1 = 100MHz`、`clk_out2 = 133.33MHz`。
3. 按开发板原理图分配引脚约束（LCD、触摸、I2C、被测信号输入 `clk_fx_ch_ext`）。
4. 综合实现后下载比特流，屏幕即显示标题、实时日期时间与各通道频率。
5. `clk_out1` 输出 5Hz 测试时钟，可将其接回任意通道输入用于自校验。

## 显示内容说明

- 顶部标题 + 蓝色边框
- 左上角两行：`20YY-MM-DD` 与 `hh:mm:ss`（来自 PCF8563）
- 右上角：实时触摸坐标 `XXXX YYYY`
- 中部 3×3 网格：每格显示 "通道N：" 与对应频率值（单位 Hz，最多 9 位数字）
- 右下角翻页图标：第一页显示"下一页"，第二页显示"上一页"，点击该区域翻页
